# Receptari de casa

Calculadores interactives de receptes (HTML estàtic), publicades amb GitHub Pages.

- `index.html`: índex de receptes (la llista és a l'script, `S.list`).
- Una pàgina autònoma per calculadora.

Per afegir una recepta: copia'n l'HTML autònom a l'arrel i afegeix-ne l'entrada a `S.list` d'`index.html`.
